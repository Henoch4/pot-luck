Model

A circle is created with a fixed contribution, a number of rounds, and an ordered member list. Members contribute in list order; when every member has paid for the current round, the contract instantly pays the pot to the member whose turn it is:

round r payout = contribution × memberCount  →  members[r % memberCount]

paidLedger[circleId][round][member]  →  exactly one payment per member per round
require(memberList includes msg.sender)  →  creator must participate

State transitions are emitted as events (CircleCreated, Contributed, Payout) — the contract itself never holds anything but the current round's pot.
