Why Potluck

The rotating savings model used worldwide — tamaho, hagbad, susu, tontine — with the custody problem solved.

🏦

Contract custody

Contributions sit in the Potluck contract between rounds. Nobody can run with the pot, and nobody can be "late" twice.

⚙️

Deterministic payouts

When the last member of a round pays, the contract instantly sends the pot to that round's member — same block, no admin.

🔍

Fully verifiable

Every contribution and payout is an explorer transaction. Your circle state is public, auditable, and cannot be rewritten.

How it works

Create once, contribute per round, get paid once.

01

Create a circle

Pick a contribution amount, number of rounds, and the member list (including yourself).

02

Contribute each round

Each member transfers the fixed contribution into the contract for the current round — once per round.

03

Collect the pot

When all members have paid, the pot goes to that round's member. Order is fixed at creation — no favoritism.
